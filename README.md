# AI 8-Puzzle Solver

A puzzle game that solves itself automatically using AI.

## Description
An interactive 8-puzzle game where the player can solve 
the puzzle manually or let the AI solve it automatically 
using the A* search algorithm.

## Features
- Manual play using keyboard
- Auto-solve using A* Algorithm
- Graphical User Interface (GUI)
- Random puzzle shuffle

## Technologies Used
- Python
- A* Search Algorithm
- Manhattan Distance Heuristic
- Tkinter (GUI)
